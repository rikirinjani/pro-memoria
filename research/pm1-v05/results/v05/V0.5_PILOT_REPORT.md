## 6. Scaling Behavior (measured, not assumed)

Fits to cumulative tokens vs horizon (3 points: 10, 50, 100):

| Series | Linear R² | Quadratic R² | Conclusion |
|---|---|---|---|
| P cumulative tokens | 0.9999 | 1.0000 | **linear** (quadratic term ≈ 0) |
| C cumulative tokens | 0.9475 | 1.0000 | **quadratic** (quadratic term 25.69) |
| P transmitted context | 1.0000 | 1.0000 | exactly linear (slope 79.0) |
| C transmitted context | 0.9337 | 1.0000 | **quadratic** (term 21.58) |

Measured conclusion: P scales ~O(N) in cumulative transmission; C scales
super-linearly, best fit quadratic ~O(N²). These are measured fits, not
assumptions — with only 3 pilot horizons the quadratic-vs-linear R² gap is
indicative; the 7-horizon full experiment will confirm.

## 9. Critical Fairness Check

- **C genuinely carries conversational history:** transmitted_context_chars
  grows 46 → 14,792 and history_size grows monotonically 0 → 14,745; per-hop
  input tokens grow 299 → 4,608, proving the provider consumed the
  accumulating transcript (no unintended context compaction/reuse).
- **P receives no hidden information:** P's only input is the bounded PM-1
  packet (318 chars, same content as the state C also sees in its last line);
  no expected action, oracle output, horizon, trial, scenario, seed, or token
  count is present (prompt-isolation tests + per-hop record inspection).
- Both conditions share: same task, same model, same initial state, same
  schedule, same success criteria. Only the transmission mechanism differs.
- No fairness or instrumentation defect discovered.

## 10. Measurement-vs-interpretation Attribution

- **Measured result:** 320/320 PASS; P cumulative tokens {4,926 / 24,810 /
  48,816}; C {5,357 / 63,802 / 252,455}; P context bounded at 318 chars; C
  context grows to 14,792 chars; C quadratic fit R²=1.0 vs linear 0.9475.
- **Implementation artifact:** the transcript format (state/action pairs +
  current line) is a stylized conversation; it accumulates by construction
  and the API token counts confirm real growth.
- **Model behavior:** deepseek-v4-flash solved the task identically under both
  conditions (100% correctness); output tokens stayed small and flat.
- **Protocol behavior:** PM-1 bounded transmission carries sufficient state;
  conversational transmission carries the same state plus growing history.
- **Interpretation:** PM-1 shows linear scaling and growing relative savings;
  this is a pilot-scale indication to be confirmed by the 7-horizon full run.
